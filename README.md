# ŠACH KVÁK MEK!!!

A personalized chess app for a young competitive player. Phase 1 is a local
human-vs-human board in the browser: both players move on the same screen, only
legal moves are accepted, and the game ends correctly (checkmate, stalemate,
insufficient material, threefold repetition, fifty-move rule). All rules come from
`chess.js`; `@lichess-org/chessground` only renders the board. Later phases add a
custom piece set (frogs vs. goats), an engine opponent and PWA packaging.

## Commands

```powershell
npm install
```

```powershell
npm run dev
```

